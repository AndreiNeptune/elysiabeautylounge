# Contributing to Elysia Beauty Lounge

Thank you for contributing! Please follow these guidelines to keep the codebase clean and maintainable.

## Development Workflow
1. Create a descriptive branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your changes in the `/src` folder or layout files.
3. Verify changes locally by running `npm run dev`.
4. Ensure your CSS styles follow the custom design system tokens in `variables.css`.
5. Keep your JS logic modular and clean.

## Commit Guidelines
We use [Conventional Commits](https://www.conventionalcommits.org/):
*   `feat:` for new features (e.g. `feat: add new service section`)
*   `fix:` for bug fixes (e.g. `fix: adjust navigation offset on mobile`)
*   `chore:` for build tasks, dependencies, etc. (e.g. `chore: update packages`)
*   `docs:` for documentation updates
